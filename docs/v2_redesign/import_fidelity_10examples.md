## Deliberately ignored zones

These cell zones are read by SheetJS but the parser does NOT store them — by design. They are not bugs.

- **Row 13 (entire row)** — column-header anchors (`Pos.`, `Bezeichnung`, `EP`, `Min/Einheit`, etc.). Validated as labels, not stored.
- **Row 1** — reserved/blank in the template.
- **Header labels** — `A2`/`A4`/`A6`/`A8` ("AG:" "Leistung:" "BV:" "Bieter:"), `D2`/`D4` ("Abgabedatum:" "Vergabenummer:"), `C8`/`C9`/`C10` ("Netto/MwSt./Brutto Angebotssumme"), `I2-I12` left-column labels ("Stoffe:" "Nachuntern.:" "Gerätekosten:" "Lohn:" "Mitarbeiter:" "Arbeitstage:" "Zeitwert:" "Stoffe"), `K3-M3` matrix headers ("EINKAUF" "ZSCHLG" "VERKAUF" "DIFFERNZ"), `K8`/`K9`/`M8` ("Ges. Std.:" "Monate:" "Überschuss:"), `L11` ("Kontrollsmm.:"), `M12` ("NU"), `J10`/`K10`/`M10` ("kWp:" + "-" placeholders), `L2` ("Stundensatz:"), `J12` ("Bei Mitarbeiter-Einsatz:"), `AE11`/`AM11`/`AP11`/`AC12-AN12`/`X12-AB12` (internal notes, matrix titles, sidebar param labels), `AF10` ("Kontrollsumme:" — even though `AG10` value IS captured indirectly via `headerExtras.kontrollsumme`).
- **Sidebar reference matrices, cols X..AP rows 2-12** — Trockenbau reference table (X-AB), Decken-Lookup (Z-AE), GP-summary panel (AE-AH), Stoffe-VK + NU-EP (AJ-AK), AM-AN (Tagen/Gesamt summary), AP (parameter overrides: Geräte-Z., Zeitwert %, Std./Tag, EP, Stunden). These are static lookup data for Excel formulas, not user-editable per-project parameters.
- **Position-row derived columns (rows 14+)**: `E` (EP), `F` (GP), `G`/`H` (blank), `K`/`L` (Lstg./Std. = 60 / Min-Einheit), `N..W` (Faktoren formula args), `X..AP` (Stoffe-Zeit, Zulagen, GP per cost type, Tagen, Gesamt, EP pro Stunde, EP-Stunden — all formula-derived).

**Implication:** if a fixture has a non-empty cell in one of the above zones that PART R/W ever decides to capture, the zone map in `classifyCell()` must be updated.
